# Temp Watcher
*Personal project / actively developed.*

Temp Watcher is a Windows application that monitors your PC's system statistics and makes them available over your local network.

## Features

- CPU temperature
- GPU temperature
- Local network API
- Runs in the Windows system tray
- Designed to work with the companion Wear OS app

## Requirements

- Windows 10/11 (64-bit)
- [pawnIO](https://pawnio.eu/) (required for some sensors)
- No separate .NET installation required

## Installation

Download the latest release from the [Releases](../../releases) page and run `TempWatcher.exe`.

Once running, Temp Watcher will be available from the Windows system tray.

## Companion App

The [Wear OS companion app](https://github.com/Qualyyy/temp-watcher-wear-app) connects to Temp Watcher over your local network to display your PC's statistics.
